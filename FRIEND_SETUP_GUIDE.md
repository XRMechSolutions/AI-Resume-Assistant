# Job Search Project Setup Guide

This guide helps you set up an AI-assisted resume customization system that prevents hallucinations and creates human-authentic application materials.

---

## How This System Works

This system uses Claude Code to:
1. **Prevent fabrication**: Claude only uses skills/experience from YOUR verified source documents
2. **Customize resumes**: Tailors your resume for each job without adding fake experience
3. **Write authentically**: Avoids AI-sounding language that triggers rejection
4. **Generate PDFs**: Creates professional PDFs from text files

## STEP 6: How to Use the System

1. **Create folder**: `JobSearches/[CompanyName]/`

## Anti-Fabrication Safeguards

The system is designed to prevent Claude from:

1. **Adding technologies you don't know** - Claude checks your DO NOT CLAIM list
2. **Inventing metrics** - Only uses numbers from your source document
3. **Embellishing experience** - Sticks to your exact descriptions
4. **Using AI-sounding language** - Follows human-authentic writing guidelines

### If Claude tries to add something suspicious:

Ask: "Can you show me where in my source documents this skill/achievement is documented?"

If Claude can't point to the exact line, remove that claim.

## Troubleshooting

### Problem: Claude adds skills I don't have
**Solution**: Check that your DO NOT CLAIM list is comprehensive and that CLAUDE.md explicitly references it

### Problem: Resumes sound too "AI-generated"
**Solution**: Ensure RESUME_CRAFTING_GUIDELINES.md is being read; ask Claude to "make this sound more human"

### Problem: PDF doesn't format correctly
**Solution**: Check that your .txt file follows the expected section headers (PROFESSIONAL EXPERIENCE, TECHNICAL SKILLS, etc.)

### Problem: Claude ignores my source documents
**Solution**: Start your request with "First read my truth document at [path], then..."
